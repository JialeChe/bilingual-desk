翻译对照 · Windows 64 位

双击“翻译对照.exe”即可运行，无需安装 Python，也无需管理员权限。

首次使用
1. 默认使用 DeepSeek API；点击左上角“设置”填写密钥，也可切换为本地 Codex。
2. DeepSeek：填写自己的 DeepSeek API Key，账户需要有 API 余额。
   本地 Codex：需在本机安装 Codex，并使用自己的 ChatGPT 订阅登录。
3. 左侧输入中文，或右侧输入英文；也可点击“打开文件”导入 TXT / Markdown / 双语 JSON 文档。
4. 左侧中文、右侧英文，两栏都可以修改，程序更新另一侧对应内容。
5. “自动翻译”可以直接在主界面开关。关闭后点击“翻译 / 更新”或按 Ctrl+Enter。

双向编辑
修改一个词或一段话后，程序将涉及的完整句子交给模型，直接用整句译文更新另一侧。
旧文档里拆开的短片段会合并回整句；无需模型提供新增文字的插入位置。
两侧修改不同句子时，会分别同步。同一句两边都改过时，程序保留内容并提示
“以中文为准 / 以英文为准”。选择前会自动备份，只有冲突句子使用所选版本。
首次翻译前两侧都有内容时，也需先选择以哪边为准。

段落对齐
已有对应关系的中英文段落使用相同显示高度，较短一侧自动补显示留白。
编辑任意一侧、调整字号或窗口宽度后会重新对齐，两侧滚动保持同步。
留白只用于显示，不影响复制、保存、导出或撤销；段落内部的换行位置可以不同。
未同步的新增换行缺少对应位置时，会先与相邻内容一起对齐。

大文档初始化
首次翻译自动分批，显示完成批数；全部校验通过后统一显示结果。
失败或取消后，内容不变时可点击重试，继续使用本次运行已完成的批次。
已完成批次仅保留在内存；退出程序、切换引擎或修改内容后需重新处理。
设置里的等待时间针对每批，大文档整体可能需要数分钟。

常用操作
Ctrl+Enter：翻译 / 更新
Ctrl+S：保存双语 JSON 文档
Ctrl+O：打开文档
Ctrl+F：查找
Ctrl+Z / Ctrl+Y：撤销 / 重做
主界面“复制英文”：复制右侧全部英文。
“文档”菜单：最近文档、恢复备份、分别复制或导出中文、英文 TXT / Markdown。
翻译期间可点击“取消翻译”，保留原文和现有译文。

文档和设置
程序自动保存草稿，重启后恢复。需要长期保存或分享时，请使用 Ctrl+S 保存文档。
程序数据保存在：%LOCALAPPDATA%\BilingualDesktop
开发版工作目录中的旧数据不会自动迁入；可用开发版保存的 JSON 文件继续编辑。
新版可读取旧版 v1 文档，保存为 v2 格式，两侧未同步的修改也会保存。
API Key 通过当前 Windows 用户加密保存，换电脑或更换 Windows 账号后需重新填写。
